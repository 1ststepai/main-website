Local commands

Cycle 1 compiles a Project OS markdown ZIP on your machine. No model is called. Do not deploy the unauthenticated compile API.

git clone https://github.com/1ststepai/1ststep-os
cd 1ststep-os
npm install && npm test && npm run build && npm start
Then open http://localhost:3000/os
Paste an idea → compile → download a Project OS markdown ZIP.
Node 22 or newer. Local only.

What it does now

  1. Clone the public GitHub repository.
  2. Install, test, build, and start on localhost.
  3. Open /os, paste an idea, compile a markdown ZIP.
  4. Keep project memory in files. Conversations stay disposable.

This is Cycle 1 of the free core, not a hosted runtime. The companion CLI for existing repos is OS Audit.
