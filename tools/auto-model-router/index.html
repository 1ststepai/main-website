Suggest a lighter model tier. Confirm before it runs.

Auto Model Router is a portable policy for Cursor, Claude, Codex, and other multi-model agents. It classifies work into the lightest sufficient tier, shows the suggestion, and waits for you to confirm or override. The skill stays usable without an email—this page is only for optional feedback.

Honest scope

This is a readable heuristic, not trained routing ML and not a billing dashboard. Usage savings happen only if the confirmed lighter tier is mapped to a cheaper or faster model (or lower effort) and that mapped choice is what actually runs. Percentages in the repo estimator are relative comparisons from a local log, not vendor invoices or promised savings.
