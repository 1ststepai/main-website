YouTube

Private unless you change it

YouTube sign-in needs a Google OAuth Desktop client saved on this computer. PostPath does not include a Google app.

  1. In Google Cloud Console, create or open a project and enable YouTube Data API v3.
  2. OAuth consent screen: add the scope youtube.upload. While the app is in Testing, add your Google account as a test user. Refresh tokens in Testing last about seven days.
  3. Create an OAuth client of type Desktop app. Copy the client id and client secret into App credentials below. Do not commit them.
  4. If Google asks for a redirect URI, paste the Google loopback URI. Desktop clients often allow http://127.0.0.1 with this port already.
  5. Connect YouTube, then save a draft. Privacy starts at Private. A vertical MP4 of 3 minutes or less is what YouTube treats as a Short after processing. PostPath does not crop the file.
  6. An unverified app can be limited to private uploads. videos.insert costs 1,600 quota units. A new project’s default is 10,000 units per day.

Google loopback URI: http://127.0.0.1:47831

No draft yet. Publishing uses the draft you just saved.

Uninstalling PostPath leaves saved accounts in place. Remove them only with the button below, then quit and open PostPath again. This installer is unsigned. Leave Windows SmartScreen and macOS Gatekeeper on.

Facebook and Instagram

Page draft unless you choose Public

Meta sign-in needs your Meta app id and app secret saved on this computer. PostPath does not include a Meta app.

  1. Create a Meta app, type Business. Add Facebook Login and the Instagram product.
  2. Add the Facebook user as an app admin, developer, or tester. In Development mode that is enough for your own Page. Other people’s accounts need App Review for instagram_content_publish and pages_manage_posts.
  3. Connect a Facebook Page you manage. For Instagram, the account must be a professional (Business or Creator) account linked to that Page.
  4. Valid OAuth redirect URI: the provider URI below. Save META_APP_ID and META_APP_SECRET in App credentials.
  5. A video file on this computer is uploaded to Meta with their resumable upload. Facebook stays an unpublished Page Reel unless privacy is Public. Instagram has no private publish: PostPath will not upload it until you set Public.
